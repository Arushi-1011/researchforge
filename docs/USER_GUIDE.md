# ResearchForge user guide

## Current preview
The dashboard preview presents project cards, research activity, workspace navigation, and a research tip. Its sample metrics are static preview data at this phase.

## Planned research workflow
1. Create a workspace project.
2. Search arXiv/Semantic Scholar or upload a valid text-layer PDF.
3. Review and correct deterministic extracted fields.
4. Organize papers with categories and tags.
5. Compare two or more papers and capture gap notes.
6. Use Premium AI actions only when explicitly requested.
7. Generate a structured project document and export PDF or Word.

The complete workflow becomes available as subsequent phases are implemented.
